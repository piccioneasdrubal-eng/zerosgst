# ZeroLegend — ESC Menu

Premendo ESC durante il gioco si apre il Menu Utente. Premendo ESC di nuovo lo chiude.

Il menu contiene le sezioni Profilo, Gioca, Shop, Statistiche, Impostazioni e Altro/Aiuto.

Mentre il menu è aperto il client sospende l invio dei target mouse, così la partita non continua a ricevere nuovi comandi di movimento dal browser.

Aggiorna sia `UPLOAD-FTP/` sul sito sia la copia `BACKEND-NODE/public/` se usata. Dopo l upload fai Ctrl+F5.
