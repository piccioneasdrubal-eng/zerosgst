ZEROLEGEND - INSTALLAZIONE INFINITYFREE

1) Apri htdocs nel File Manager.
2) Carica TUTTO il contenuto di questa cartella direttamente in htdocs.
3) Importa auth/migrate.sql in phpMyAdmin.
4) Importa game/migrate.sql in phpMyAdmin.
5) Controlla auth/db-config.php.
6) Apri https://zerothelegend.gamer.gd/auth/auth.php?health=1
7) Apri https://zerothelegend.gamer.gd/game/game.php?action=health
8) Fai Ctrl+F5.

QUESTA VERSIONE NON USA RENDER, NODE.JS O WEBSOCKET.
Il multiplayer passa da PHP + MySQL con polling HTTP.
